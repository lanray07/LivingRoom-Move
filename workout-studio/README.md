# LivingRoom Move workout review studio

Ten editable 1080p session drafts, totalling 100 minutes. Every composition is an unreviewed production preview with synthetic speech. Cue cards are not instructor demonstrations. See [content scope and rights](../content/README.md).

Start with `npm ci`, then `npm run dev -- --no-open`. Use `node ../tools/render_workout_reviews.mjs` from this directory, or `node tools/render_workout_reviews.mjs` from the repository root, for full-duration local review exports after generating the audio. Generated media is excluded from Git.

## Commands

**Install Dependencies**

```console
npm i --loglevel=error
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```
